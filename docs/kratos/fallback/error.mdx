title: This should be the Error UI
---

You ended up here because you didn't set the following configuration value:

```yaml title="path/to/kratos/config.yml"
selfservice:
  flows:
    error:
      ui_url: http://my-app.com/error
```

You can set this configuration value using environment variable `SELFSERVICE_FLOWS_ERROR_UI_URL` as well!

If you don't know what that means, head over to [User-Facing Error](../self-service/flows/user-facing-errors.md)!
অলস কৃষকের দুপুরের আড্ডা
​(দৃশ্য ১: খোলা মাঠ)
ক্যামেরাটি সুন্দর একটি সবুজ মাঠের ওপর দিয়ে প্যান করে যাচ্ছে। দূরে দেখা যাচ্ছে একটি গরু এবং একটি ছাগল মনের সুখে ঘাস খাচ্ছে। গরুটা শান্তভাবে ঘাস খাচ্ছে, কিন্তু ছাগলটা কিছুক্ষণ পরপর এদিক-ওদিক লাফিয়ে বেড়াচ্ছে।
​(দৃশ্য ২: গাছের নিচে কৃষক)
ক্যামেরা ধীরে ধীরে সরে এসে মাঠের মাঝখানে থাকা বড় একটি বটগাছের নিচে থামল। কৃষক মোবারক সেখানে লুঙ্গি পরে বেশ আয়েশ করে গাছের গুড়িতে হেলান দিয়ে বসে আছেন। তার পাশে একটি পুরনো হাতপাখা পড়ে আছে, যা তিনি মাঝে মাঝে আলসেমি করে নাড়াচ্ছেন।
​(দৃশ্য ৩: মজার কথোপকথন)
মোবারক গরু আর ছাগলের দিকে তাকিয়ে নিজের মনেই কথা বলছেন:
"ওরে গরু ভাই, তুই তো শান্তি মতো খাচ্ছিস। আর তুই ছাগল? তোর কি কোনোদিন পেট ভরবে না? তুই তো দেখি আমার সব সবজি খেয়েই শেষ করলি!"
​মোবারক একটু হাই তুলে আবার বললেন, "আরে ভাই, এই দুপুরের রোদে কাজ করা কি আমার কাজ? প্রকৃতির হাওয়া আর গাছের ছায়া—এর চেয়ে আরাম আর কী আছে? আর গরু-ছাগল তো নিজেরাই নিজেদের খাবার খুঁজে নিচ্ছে, তারা যদি খেয়েই পেট ভরে নেয়, তবে আমার আর কিচ্ছুটি করার দরকার নাই!"
​(দৃশ্য ৪: ক্লাইম্যাক্স)
হঠাৎ ছাগলটা দৌড়ে এসে মোবারকের পাশের গামছাটা মুখে নিয়ে টান দিতে শুরু করল। মোবারক চমকে উঠে বসা থেকে লাফিয়ে উঠলেন, "আরে! আমার গামছা ছাড়! তুই তো দেখি আমারই খাবার কেড়ে নিচ্ছিস!"
​মোবারক দৌড়ে ছাগলের পিছু নিলেন, আর ক্যামেরাটা কাঁপতে কাঁপতে সেই মজার দৃশ্য ধারণ করল।
​(শেষ দৃশ্য)
মোবারক হাঁপাতে হাঁপাতে ক্যামেরার সামনে এসে হাসতে হাসতে বললেন, "বন্ধুরা, অলস হওয়ার ফল যে কী, তা আজ হাতে-কলমে শিখলাম! সাবস্ক্রাইব করে সাথেই থাকুন!"
